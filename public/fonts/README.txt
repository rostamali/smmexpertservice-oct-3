CUSTOM LOCAL FONT FOLDER

Put self-hosted font files here, for example:
  public/fonts/MyFont-Regular.woff2
  public/fonts/MyFont-Bold.woff2

The storefront currently uses Google Manrope through next/font/google.
If you later want to switch to a local font, edit:
  src/lib/storefront-font.ts

Example path in next/font/local:
  ../../public/fonts/MyFont-Regular.woff2
